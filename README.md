# NekoQuest — Pixel RPG Mobile

Planner mobile em estilo RPG de gatinhos pixel art, com missões, calendário, Pomodoro, histórico, perfil e recompensas personalizáveis.

## Publicar no GitHub Pages
1. Extraia este ZIP.
2. Envie todos os arquivos para a raiz do repositório.
3. Em Settings → Pages, selecione Deploy from a branch, `main`, `/ (root)` e salve.
4. Abra o endereço HTTPS publicado no smartphone.

Os dados ficam no armazenamento local do navegador e não sincronizam automaticamente entre dispositivos.
